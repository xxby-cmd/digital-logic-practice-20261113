# 课程练习室

本地使用的课程刷题网站。目前开放计算机网络、数据结构、程序设计基础C、数电设计；大学物理等待指定教材。各章百题是持续建设目标，现有题量与缺额见网站章节列表和仓库外“制作记录/总目标进度”，不能将目录存在当作题库已齐。

## 答题方式

- 逐题练习：先选题型，再筛章节、随机抽取、本轮不重复，可主动查看解析，不累计考试积分。
- 章节练习：默认20题，可在设置中调整总量、参与题型或各型数量，保存全科默认或本科覆盖。只从本章抽题，同组不重复，库存不足明确提示。整组作答自动保存，提交后核对答案，不限时、不计积分；每组1至100题、统一100分。原生判断题不足时，从未被本组使用的选择题改为判断给定答案是否正确。普通填空与程序填空仍区分。旧章节记录继续保留。
- 限时考试：完整期末卷，120分钟、100分；刷新不重置期限，到时自动锁答。交卷后才显示解析。客观题自动核对，已接入的纯功能代码题编译测试，新答卷中的简答与代码分析题提交后由本机Codex评阅；旧自评答卷保持原模式。首次结算后成绩和积分固定，错题重做不改分。
- 每题两个名词短注随网站预存，普通展开不联网。主动划词解释和追问使用本机Codex；考试交卷前关闭这些辅助。
- 作答保存在当前浏览器，可备份恢复。文件版与本地HTTP版属于不同存储位置，换入口前请备份。

## 完整卷模板

| 科目 | 题型与数量 | 分值 | 依据 |
|---|---|---|---|
| 计算机网络 | 选择15、填空9（10空）、分析5、计算5 | 15/10/30/45 | 用户提供2023 A卷 |
| 数据结构 | 判断10、选择9、填空6、应用5、算法2 | 20/18/12/40/10 | 用户提供2021期末卷 |
| 数电设计 | 基本5、分析3、设计3 | 36/32/32 | 用户提供2023—2024模拟卷 |
| C语言 | 选择20、程序填空5、编程10 | 暂拟20/20/60 | 用户指定题量，仍缺真实期末卷 |

每科现有一套新版完整卷，旧半卷答卷与章节记录保留恢复。用尽后提示补题，不用重排旧题冒充下一套。

## 本地启动

基础网站只需Node.js 20或更新版本，无需安装前端依赖，也不要求先安装Python。在项目目录运行：

```sh
npm start
```

首次启动自动构建，打开终端显示的 `http://127.0.0.1:4174`。Windows也可双击“启动练习室.cmd”。已有构建会保留其中的本地参考题；修改源码后使用 `npm run dev` 重新构建并启动。

编译判题为可选功能。Windows首次运行 `scripts/setup-judge.ps1`，在仓库外准备固定版本的Python运行环境、Zig及Wasmtime，随后重新启动网站即可识别。也可用 `JUDGE_PYTHON`、`JUDGE_ZIG` 指定已有可执行文件。未准备编译环境时，网站可正常练习并保存代码，运行与判题需环境就绪。Linux/macOS可运行基础网站，真实C编译环境需另行准备，本轮没有验证这些系统的真实编译。

Java判题需要Windows、可用Python和JDK 21；默认查找 `C:/Program Files/Java/jdk-21`，可用 `JUDGE_JAVA_HOME` 指定同版本目录。不依赖Zig或C编译器；运行环境未就绪时保留作答供重试。当前没有验证其他系统的Java隔离运行。提交后AI评阅与自由追问另需本机已登录的Codex；普通做题和静态名词短注不需要登录。

其他命令：

```sh
npm run build       # 构建默认源码版
npm run check       # 默认构建并执行普通测试
npm run start:local # 显式构建本机参考题版并启动
```

服务只监听本机。GitHub自动检查仅构建与测试，不含部署、Pages或发布步骤；当前没有公网网站。

`npm run build:local`仅供原资料所在本机使用，从仓库外的“已接入题目.json”注入参考原题。“已核验题目.json”用于并行整理的候选，复核后才合并到接入快照，未接入题不计网站题量。默认构建排除第三方原题。`dist/index.html`可双击打开；代码运行仍需本地服务，纯静态HTML本身不会执行C或Java程序。

## 编程判题范围

已接入的C练习、数据结构76道算法题与新版完整卷代码题具有服务端测试。首批13道数据结构算法题另有Java接口：绪论4道、内部排序9道。适配题的新空白作答默认Java，也可切回C；已写旧答案仍按原语言保存。具体版本与范围以 `coding-catalog.js`、`java-task-guides.js` 和对应服务端契约为准。数据结构算法题尚未全部接入，不能声称所有编程题都已自动判题或支持Java。

函数题只提交题目指定的函数；Java方法题提交完整的Solution类，提供的记录类型不重复定义。系统提供测试入口；片段填空会提供完整提交接口。练习可自定义输入运行完整程序，Java自测使用含main的Main类，正式判题使用服务端测试。考试交卷后才开始判题；服务未连接保留答卷供重试，不直接记零。代码测试通过不能代替独立的复杂度、次数或证明子问，这些题提交后结合运行证据整体评阅。有限测试不能证明复杂度和指定算法要求。

C17程序编译为WASI，在限制时间、计算量、64MB内存和64KB输出的环境运行，不开放宿主文件目录和网络；支持常用标准头文件及普通宏定义。学生源码限32KB，受信驱动单独计算。当前仅为个人本地学习环境，未作为公开多人判题平台验收。

Java 21编译和运行使用Windows AppContainer与Job约束，堆64MB、进程内存512MB，学生编译12秒、运行3秒、输出64KB。可信测试准备与学生编译分阶段检查，并核对精确方法签名；功能判题不回传私有测试输出或运行报错原文。服务外层超时保待判；测试入口运行时的非零退出统一报告运行错误，驱动本身须通过参考与等价实现核验。这些为本机课程用途的实际边界，不是公网判题服务的安全认证。

## 题库范围与许可

默认构建含四门课程的 3,711 道原创练习题。教材、PPT、原始试卷、第三方参考题和个人作答均保存在仓库外。代码与原创题库尚未指定开源许可。维护与验证见 `CONTRIBUTING.md`。

验证包括题库结构、独立推导、计时锁答、判题与首次锁分、备份恢复、构建页面，以及有本地编译环境时的实际编译测试。真实C测试需设置 `JUDGE_RUNTIME=1`、`JUDGE_PYTHON`、`JUDGE_ZIG`，Java测试另用 `JUDGE_JAVA_RUNTIME=1` 与JDK 21；普通测试会明确跳过运行环境项目。浏览器实测与源码检查分别保留记录，不代表所有题库或命题风格均已获用户认可。
