# 课程练习室

本地使用的课程刷题网站。目前开放计算机网络、数据结构、程序设计基础C、数电设计；大学物理等待指定教材。各章百题是持续建设目标，现有题量与缺额见网站章节列表和仓库外“制作记录/总目标进度”，不能将目录存在当作题库已齐。

## 答题方式

- 逐题练习：先选题型，再筛章节、随机抽取、本轮不重复，可主动查看解析，不累计考试积分。
- 章节练习：每章点击“开始练习”，可选30选择、20选择＋10填空、20选择＋5填空＋5编程，或自定义判断、选择、填空、编程题量。快捷方案可勾选额外加入3至5道判断题。只从本章抽题，同组不重复，库存不足明确提示。整组作答自动保存，提交后核对答案，不限时、不计积分；每组1至100题、统一100分。原生判断题不足时，从未被本组使用的选择题改为判断给定答案是否正确。普通填空与程序填空仍区分。旧章节记录继续保留。
- 限时考试：完整期末卷，120分钟、100分；刷新不重置期限，到时自动锁答。交卷后才显示解析。客观题自动核对，已接入的代码题编译测试，其余主观题自评。首次结算后成绩和积分固定，错题重做不改分。
- 作答保存在当前浏览器，可备份恢复。文件版与本地HTTP版属于不同存储位置，换入口前请备份。

## 完整卷模板

| 科目 | 题型与数量 | 分值 | 依据 |
|---|---|---|---|
| 计算机网络 | 选择15、填空9（10空）、分析5、计算5 | 15/10/30/45 | 用户提供2023 A卷 |
| 数据结构 | 判断10、选择9、填空6、应用5、算法2 | 20/18/12/40/10 | 用户提供2021期末卷 |
| 数电设计 | 基本5、分析3、设计3 | 36/32/32 | 用户提供2023—2024模拟卷 |
| C语言 | 选择20、程序填空5、编程10 | 暂拟20/20/60 | 用户指定题量，仍缺真实期末卷 |

每科现有一套新版完整卷，旧半卷答卷与章节记录保留恢复。用尽后提示补题，不用重排旧题冒充下一套。

## 本地启动

基础网站只需Node.js 20或更新版本，无需安装前端依赖，也不要求先安装Python。在项目目录运行：

```sh
npm start
```

首次启动自动构建，打开终端显示的 `http://127.0.0.1:4174`。Windows也可双击“启动练习室.cmd”。已有构建会保留其中的本地参考题；修改源码后使用 `npm run dev` 重新构建并启动。

编译判题为可选功能。Windows首次运行 `scripts/setup-judge.ps1`，在仓库外准备固定版本的Python运行环境、Zig及Wasmtime，随后重新启动网站即可识别。也可用 `JUDGE_PYTHON`、`JUDGE_ZIG` 指定已有可执行文件。未准备编译环境时，网站可正常练习并保存代码，运行与判题需环境就绪。Linux/macOS可运行基础网站，真实C编译环境需另行准备，本轮没有验证这些系统的真实编译。

其他命令：

```sh
npm run build       # 构建默认源码版
npm run check       # 默认构建并执行普通测试
npm run start:local # 显式构建本机参考题版并启动
```

服务只监听本机。GitHub自动检查仅构建与测试，不含部署、Pages或发布步骤；当前没有公网网站。

`npm run build:local`仅供原资料所在本机使用，从仓库外的“已接入题目.json”注入参考原题。“已核验题目.json”用于并行整理的候选，复核后才合并到接入快照，未接入题不计网站题量。默认构建排除第三方原题。`dist/index.html`可双击打开；代码运行仍需本地服务，纯静态HTML本身不会执行C程序。

## 编程判题范围

已接入的C练习、数据结构栈/队列题与新版完整卷代码题具有服务端测试，具体范围以 `coding-catalog.js` 和对应服务端契约为准。数据结构练习中的其他算法题尚未全部接入，不能声称所有编程题已自动判题。

函数题只提交题目指定的函数，系统提供测试主函数；片段填空会提供完整提交接口。练习可自定义输入运行完整程序，正式判题使用服务端测试。考试交卷后才开始判题；服务未连接保留答卷供重试，不直接记零。测试通过获得该代码题分数，复杂度、算法方法和文字说明仍需对照解析核查，有限测试不能证明这些性质。

C17程序编译为WASI，在限制时间、计算量、64MB内存和64KB输出的环境运行，不开放宿主文件目录和网络；支持常用标准头文件及普通宏定义。学生源码限32KB，受信驱动单独计算。当前仅为个人本地学习环境，未作为公开多人判题平台验收。

## 数据与开源边界

当前仓库私有、本地使用；本次允许推送源码，不部署到公网。后续公开或部署仍需明确授权。教材、PPT、原始试卷和第三方题目原件在仓库外，个人练习记录不入库。默认源码包含原创题库和来源说明；开源前仍需完成许可选择与逐项审核。维护说明见 `CONTRIBUTING.md`。

验证包括题库结构、独立推导、计时锁答、判题与首次锁分、备份恢复、构建页面，以及有本地编译环境时的实际C编译测试。真实编译测试需设置 `JUDGE_RUNTIME=1`、`JUDGE_PYTHON`、`JUDGE_ZIG`；普通测试会明确跳过这些项目。浏览器已实测代码提交与交卷后自动评分；这不代表所有题库或命题风格均已获用户认可。
