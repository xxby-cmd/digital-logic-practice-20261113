# 数电练习室

数字电路设计前五章的在线章节练习。题面、题型导航和题号区参考PTA的使用结构，采用独立视觉与实现，不使用PTA标志、源码或题目。

## 使用

- 选择章节，按单选、填空、简答筛选；支持知识点搜索、重点与作答状态筛选。
- 单选、填空题即时核对；简答题包含计算、分析与设计，提供参考作答、核对要点，由学习者自评。
- 未提交的答案自动保存为草稿，提交后显示解析。支持收藏、错题回练、记录备份和导入。
- 数据仅保存在当前浏览器，不提供账户、云端批改或跨设备自动同步。导入合并同题最近的有效记录。

## 运行与验证

需要Node.js 20或更新版本，无第三方运行依赖。

```sh
npm run dev
npm test
npm run build
```

本地访问终端显示的地址。构建后可将 `dist/` 发布到支持静态文件的托管服务；使用hash路由，子目录部署无需重写规则。

## 内容范围

| 章节 | 题数 | 练习定位 |
|---|---:|---|
| 1 概述 | 12 | 数制、编码、数字信号基础 |
| 2 逻辑代数基础 | 20 | 重点：运算、表达形式、化简 |
| 3 逻辑门电路 | 10 | 补充：当前课程概论课件标为不讲 |
| 4 组合逻辑电路 | 20 | 重点：分析、设计、典型器件与冒险 |
| 5 时序逻辑电路的存储元件 | 18 | 重点：锁存、触发、转换与时序约束 |

依据冯建文、章复嘉《数字电路设计》（西安电子科技大学出版社，2018年第一版）对应知识点与当前课程教学大纲、课件编写原创练习。重点是练习优先级，不是对考试题目的预测。首版80题是可迭代基础题库，不声称穷尽教材全部知识点。

题库数据集中在 `bank.js`；判题规则在 `grading.js`。题目修改时应保留原ID的知识含义，避免把已有学习记录错误对应到另一题。

教材、教师PPT、参考试卷和私人学习记录不纳入仓库，不随站点分发。
