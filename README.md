# 课程练习室

本地使用的课程练习网站。先选科目，再选逐题练习或限时考试。计算机网络、数据结构、程序设计基础C、数电设计已开放；大学物理等待材料。

## 使用方式

2026-11-16新增章节整组测验：选章后一次显示整组，草稿自动/主动保存不显示解析和分数；提交后统一核对，自评后保存首次成绩。章节测验不限时、不计积分，考试仍120分钟。各章显示实际题量及至少100题目标，未满足半卷类型数量的章节显示缺额；全科百题目标尚未完成。

本轮新增237原创练习，默认源码练习328；本地版另有6道核验武大原题，共334。计网物理基础100、链路101，其余章尚未达百题。第三方原题不在源码，只有`npm run build:local`从仓库外文件注入；默认`npm run build`排除原题。新6题已配合个人画像写逐步推导和易错提醒；其他旧解析未全部改写。

- 练习：从独立练习池随机抽一道，本轮不重复；可主动查看解析，练习不计考试积分。
- 考试：专用题池不进入练习。每批100分，限时120分钟，刷新不重置，到时自动交卷；交卷前没有答案和解析入口。
- 交卷时锁定作答。选择、普通填空按整题自动核对，主观题（包括程序填空、编程）交卷后对照要点自评，本站不执行C代码。
- 完成自评后首次结算，所得分数计入积分。结算后只查看错题及未满分题；重做、重复结算或导入不能改变首次成绩和积分。
- 当前每科预编2批，共134道考试题；两批用完后提示等待补题，不声称无限AI生成。独立练习数以本页最新补充为准。题量不是教材全书覆盖证明。
- 题面仅显示题号、题型和必要分值，隐藏知识点、重点、难度和工程信息。
- 记录保存在当前浏览器，可备份和恢复；旧版单科备份需进入对应科目再恢复。旧存储不删除，已撤题记录及收藏信息仍保存在迁移的历史记录中。

## 半卷题量

| 科目 | 每批题型与题量 | 依据 |
|---|---|---|
| 计算机网络 | 选择8、填空5、分析3、计算3，共19 | 2023计算机网络A卷 |
| 数据结构 | 判断5、选择5、填空3、应用3、算法1，共17 | 2021数据结构A卷题型标题及题号 |
| 数电设计 | 选择5、填空5、分析2、综合1，共13 | 2011—2012数字电路期末卷 |
| C语言 | 选择10、程序填空3、编程5，共18 | 用户指定20/5/10的整卷参考量 |

每题型取半，奇数向上取整，填空按题而非空。分值在本练习室重新归一为100，并在同题型内分配整数分，不宣称是原卷评分。数据结构2021卷选择4缺题干，“22”卷选择题标称数量与实际题号不符，因此未逐题复制原卷。

## 本地运行

Node.js 20或更新版本，无第三方运行依赖。

```sh
npm run dev
npm run build
npm test
```

先构建再测试，测试读取最新独立HTML。`dist/index.html`可直接双击打开，或本地启动后访问终端显示的地址。文件协议的浏览器存储可能随路径、浏览器而变化，建议备份后再移动文件。

## 文件结构与边界

- `bank.js`、`bank-revisions.js`、`course-banks.js`、`practice-extra.js`：练习题及修订。
- `exam-bank.js`：独立考试题、题型模板与分值；`sessions.js`：计时、交卷、自评、首次结算。
- `progress.js`、`room-progress.js`：旧记录迁移、备份恢复；`app.js`：页面和答题交互。
- 教材、课件和参考试卷仅用于研究命题机制，原件留仓库外，不随源码分发。用户作答只在浏览器或用户导出的备份中。
- 这是本地自测网站：倒计时和成绩记录不具有服务器监考或防篡改能力，不能用作正式考试平台。
- 当前GitHub私有、本地使用。公开与推送按用户明确指示执行，开源许可尚待选择。

验证包括题库结构、独立数值/状态推导、计时与锁分逻辑、备份合并及独立HTML的模拟DOM执行。尚未完成真实浏览器视觉验收；自动检查不等于用户对命题风格的认可。编题与后续修订遵循`QUESTION_POLICY.md`和用户全局出题规则。
